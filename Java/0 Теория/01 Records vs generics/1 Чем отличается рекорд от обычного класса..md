Record это специальный вид класса, который позволяет объявить прозрачный и неизменяемый носитель данных в одну строку:

public record User(String name, int age) {}

Когда ты пишешь строчку выше, компилятор автоматически создает полноценный класс со следующим содержимым:

1. **Поля:** `private final String name` и `private final int age`.
    
2. **Канонический конструктор:** Конструктор, принимающий все аргументы из заголовка.
    
3. **Методы-геттеры:** Важный нюанс для собеседования — **они называются так же, как поля, без префикса `get`**. То есть метод будет называться `name()`, а не `getName()`.
    
4. **`equals()` и `hashCode()`:** Реализованы так, что два объекта `record` равны, если равны все их поля (сравнение по значению, а не по ссылке).
    
5. **`toString()`:** Выводит имя записи и значения всех полей (например: `User[name=Alice, age=30]`).

### 1. Таблица главных технических отличий

| **Характеристика**            | **Обычный class**                                                                       | **record**                                                                                      |
| ----------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Наследование (от других)**  | Может наследоваться от одного любого класса.                                            | **Запрещено**. Неявно уже наследует `java.lang.Record`.                                         |
| **Наследуемость (от него)**   | Можно наследоваться (если класс не `final`).                                            | **Всегда `final`**. От записи наследоваться нельзя.                                             |
| **Изменяемость (Mutability)** | Поля могут быть любыми, их можно менять через сеттеры.                                  | **Строго неизменяемый**. Все поля в заголовке неявно `private final`. Сеттеров нет.             |
| **Дополнительные поля**       | Можно объявлять любые поля где угодно в теле класса.                                    | **Запрещены** любые поля экземпляра вне заголовка. В теле можно добавлять только `static` поля. |
| **Boilerplate-код**           | Геттеры, `equals()`, `hashCode()`, `toString()` нужно писать руками (или через Lombok). | **Генерируется компилятором** автоматически на основе полей из круглых скобок.                  |
| **Именование геттеров**       | По спецификации JavaBeans: `getName()`, `isAdult()`.                                    | Точно совпадают с именами полей: `name()`, `age()`.                                             |
Пример, где record бьет обычный класс

Представь, что тебе нужен составной ключ для `HashMap` (например, координаты X и Y).

Чтобы сделать это **обычным классом**, тебе нужно написать строк 30-40 кода: объявить поля, написать конструктор, геттеры и **обязательно** безошибочно переопределить `equals` и `hashCode`, иначе `HashMap` будет работать неправильно.

Чтобы сделать это через **record**, нужна ровно одна строка:

Java

```
public record Point(int x, int y) {}
```

Он идеально подходит для ключей мап, потому что неизменяем и сразу имеет правильные `equals/hashCode` "из коробки".
