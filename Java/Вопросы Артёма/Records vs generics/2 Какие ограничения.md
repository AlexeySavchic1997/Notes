
Интервьюеры обязательно спросят, чего **нельзя** делать с записями. Запомни эти правила:

- **Наследование запрещено:** Любой `record` неявно расширяет абстрактный класс `java.lang.Record`. Так как в Java нет множественного наследования классов, `record` не может `extends` никакой другой класс.
    
- **Записи всегда `final`:** От `record` нельзя наследоваться.
    
- **Дополнительные поля запрещены:** Нельзя объявлять instance-поля (не статические) вне заголовка записи. Все поля состояния должны быть описаны в круглых скобках при объявлении.
    
- **Поля неизменяемы:** Все поля неявно `final`. Сеттеров нет и быть не может.
    

**Что МОЖНО делать:**

- Реализовывать интерфейсы (`implements Serializable`, и т.д.).
    
- Создавать статические поля и статические методы.
    
- Создавать дополнительные методы (например, для форматирования данных).
    
- Переопределять сгенерированные методы.
